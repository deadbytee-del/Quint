AU-Quint: the same app, dedicated to auto-updating

AU-Quint is Quint published under its own name and its own update channel, so it never shares update metadata with anything else and always finds the newest release on launch. Grab the file named AU-Quint (instead of Quint) on the same release page. Windows and Linux auto-update out of the box; unsigned macOS builds still can't self-install updates, same as regular Quint.

Why the desktop app

Native compiling

Uses a Java runtime already on your machine when it finds one — builds finish in well under a second instead of several.

Works offline

After the first launch, Quint runs completely offline — no internet connection needed to build plugins.

Auto-updates

New versions download in the background via GitHub Releases, so you're never stuck on an old build.

Real, typed blocks

Events, actions, sensing, logic, lists, LuckPerms, MiniMessage, and more — blocks only connect where they actually make sense.

See the Java

View the exact generated source at any time — it also works as a way to learn real Bukkit/Paper plugin development.

Import existing plugins

Drop in any plugin .jar and Quint decompiles it into readable Java, reconstructing recognizable parts as blocks.
